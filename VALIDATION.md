Относительно frontend добавлены 142 файла, изменены 7 файлов авторизации и
конфигурации, удалений нет. 79 исходных frontend-файлов сохранены без изменений;
111 файлов backend сохранены побайтно из main, четыре исходных серверных файла
адаптированы для раздельного запуска и проверок.

Браузер проверяет регистрацию, неверный и верный пароль, выход, перезагрузку,
основные страницы, создание/отправку заявки и её сохранность, чат, запрет
раздела команды для стажёра, отсутствие MSW и auth-состояния в localStorage,
HttpOnly/SameSite cookie, мобильную ширину и отсутствие JavaScript-ошибок.

Серверные тесты также проверяют CSRF/Origin, запрет повышения роли при
регистрации, ограничение попыток входа, отзыв и истечение сессии, изоляцию
заявок между пользователями, согласование наставником, запись выдачи и
повторный переход закрытой заявки.

Тесты выполнены с Python 3.12 и отдельным локальным PostgreSQL 18, созданным
только для проверки; существующий системный PostgreSQL не изменялся.
Compose задаёт PostgreSQL 16, как в main. Контейнерная сборка и запуск не
проверялись: Docker Desktop daemon в окружении не запущен. Внешний live AI
не вызывался; его контракт и обработка отказов проверены исходными тестами.

При установке сохранённых npm-зависимостей аудит обнаружил унаследованные
проблемы. Для production dependencies `npm audit --omit=dev` сообщает три:
`zod` — high, `react-router` и `react-router-dom` — moderate. Предлагаемые
npm исправления требуют major-обновлений; package.json и package-lock.json
сохранены по требованию задачи. Это отдельная работа перед публичным размещением.

В tests/conftest.py кешируются хеши одного и того же синтетического пароля
при сбросах тестовой БД. Производственная генерация и проверка паролей,
регистрация и алгоритмы хеширования не менялись этой оптимизацией.
