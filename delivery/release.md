# Состояние комплекта сдачи

Подготовлен рабочий комплект Web 1 + Web 2 для передачи команде. AI по текущему указанию пользователя остаётся в деморежиме.

| Требование кейса | Состояние |
| --- | --- |
| Исходный код и README | В репозитории, ветка integration/web1-server |
| Интерфейс и серверный сценарий | Проверены вместе через HTTP, Chrome и PostgreSQL |
| Сохранённое действие и восстановление | Проверены, повтор возвращает прежний номер заявки |
| Права и отдельная сессия оператора | Проверены интеграционными тестами и браузером |
| Тестовые данные и имитации | Есть, повторный запуск и сброс документированы |
| Тесты и отчёт покрытия | 49 проверок Python, 36 тестов интерфейса; 88,48% доступного кода |
| Презентация PDF и видео | Обновляются по объединённой сборке; режим AI указан на экране |
| SDD AI-функций | Контракт server/AI в contracts/agent.md; отдельные SDD от AI-участника ожидаются |
| Пилот и метрики | В презентации изложен план, замеров эффекта на стажёрах пока нет |
| Docker | Файлы подготовлены; запуск контейнеров ещё требуется проверить |
| Финальная загрузка на платформу | Предстоит команде после общей приёмки |

## Перед финальной сдачей

Подключить AI, когда пользователь вернётся к этому этапу, проверить его SDD и тесты. Пересчитать покрытие с новым кодом и выполнить scripts/check.py --release. Проверить Docker на машине с установленным Docker. После этих изменений обновить демонстрацию и слайды, чтобы версия сдачи совпала с версией защиты.

Требуемое покрытие строк — строго больше 80%. Текущие 88,48% относятся к коду Web 1 + Web 2, включая серверный демоадаптер. Этот процент изменится при добавлении AI-модуля.

Учебные данные и порядок согласования не подтверждены как внутренний регламент Авито. Общая занятость наставника 40–48 часов за 6 месяцев и 55–65 часов за 9 месяцев взята из условия; экономию на этом основании не заявляем.
