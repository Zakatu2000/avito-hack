# Показ объединённой сборки

Видеофайл — delivery/video/demo.webm, ~61 с, 1280×800, записан против реального стенда (Flask API + PostgreSQL, demo-режим). Презентация — delivery/presentation.pdf. Учебные данные, детерминированная политика demo-режима. Для записи используются свежие демоданные в отдельной базе.

## Подготовка

Запустите API и собранный веб-клиент по README. Включите BUDDY_DEMO_OPERATOR=1. Войдите intern-demo. Пароль учебного входа training-only передаёт веб-клиент. Перед повторным показом можно сбросить именно выделенную демобазу через python -m server.store reset-demo --confirm; её сессии завершатся.

## Последовательность на троих

| Шаг | Участник | Что показать |
| --- | --- | --- |
| 1 | Web 1 | Войти intern-demo, показать назначенную задачу и отсутствие доступа |
| 2 | Web 1 | Задать вопрос «Не могу начать первую задачу. Что делать?» |
| 3 | Web 1 | Показать предложение и подтвердить его отдельной кнопкой |
| 4 | Web 2 | Обратить внимание на возвращённый сервисом номер заявки |
| 5 | Web 1 | Перезагрузить страницу; найти прежний номер |
| 6 | Web 2 | Выйти и войти operator-demo, ввести номер, нажать «Одобрить заявку» |
| 7 | Web 1 | Вернуться intern-demo; показать approved при отсутствующем праве |
| 8 | Web 2 | Войти operator-demo, нажать «Выдать право», затем вернуться к стажёру |
| 9 | Web 1 | Показать подтверждённый доступ и нажать «Вернуться к задаче» |
| 10 | AI-участник | Объяснить доступные агенту факты и режим текущего демо; в live LLM интерпретирует намерение из закрытого набора, решение и факты — за политикой и сервером. Живой вызов в этой сборке не проверялся (нет ключа) |

Для показа без смены аккаунта используйте два независимых профиля браузера. Обычные вкладки одного профиля делят cookie, поэтому вход оператором меняет сессию и в соседней вкладке.

## Воспроизведение записи

На отдельной свежей демобазе запустите объединённую сборку с BUDDY_DEMO_OPERATOR=1. Из web/ выполните (BASE_URL — адрес стенда):

    BASE_URL=http://127.0.0.1:5051 node scripts/record-demo-video.mjs
    BASE_URL=http://127.0.0.1:5051 node scripts/capture-screens.mjs

Нужен установленный Chrome (channel chrome) и компонент записи: npx playwright install ffmpeg. record-demo-video.mjs снимает полный путь с паузами на ключевых кадрах (бейдж режима AI, номер заявки до/после перезагрузки, «одобрено, ждём право», следующий шаг, возврат к задаче), длительность ~60 с; capture-screens.mjs обновляет пять скриншотов delivery/screens. Оба скрипта изменяют демоданные — перед записью выполните reset-demo. После успешной записи команда экспортирует презентацию:

    node scripts/export-presentation-pdf.mjs

На ошибке сервиса покажите её и перечитайте workspace. При отклонённой заявке помощник направляет стажёра к наставнику. Показывайте фактическое состояние сервиса.
