# Прогон для созвона с ментором (6–8 минут, всё локально)

План проверен прогоном 2026-11-11: API-шаги 1–12 пройдены curl-ом, полный
UI-путь — Playwright/Chrome e2e (3,2 с), live-финал — реальный запрос
«я застрял с первой штукой» → propose_access, aiMode=live, ~2,9 с.

## Подготовка (за 5 минут до созвона)

Стенд поднимается по README (B2), проверенные команды (PowerShell, из корня):

```powershell
docker start first-pr-b2-db     # PostgreSQL 16 на 127.0.0.1:55432
$env:DATABASE_URL="postgresql://buddy:local-demo-only@127.0.0.1:55432/avito_buddy_demo"
$env:PYTHONPATH="."
.venv\Scripts\python -m server.store reset-demo --confirm   # свежие демоданные
npm --prefix web run build      # свежий web/dist (сервер раздаёт его на :5050)

# терминал стенда (demo-режим):
$env:BUDDY_DEMO_OPERATOR="1"; $env:AI_MODE="demo"
.venv\Scripts\python -m waitress --listen=127.0.0.1:5050 --call server.app:create_app
```

Браузер: обычное окно — стажёр, инкогнито — оператор (cookie не смешиваются).
Пароли учебные: `training-only`. Ключ live лежит в `ai/.env` (в git не входит).
