# Интерфейс AI-buddy

Запуск приложения, тестовые аккаунты и порядок проверки описаны в [корневом README](../README.md). После запуска витрина дизайн-системы доступна на [странице `/design`](http://localhost:5177/design).

## Проверки фронтенда

```sh
npm ci
npm run typecheck
npm run lint
npm run build
npm run test:coverage
```

Vitest сохраняет отчёт в `coverage/`. Результаты текущего замера опубликованы в [отчёте о покрытии](../COVERAGE.md).

## Устройство

- `src/api/` и `src/services/` содержат клиент портального API и Zod-схемы.
- `src/pages/` и `src/components/` содержат экраны портала и компоненты интерфейса.
- `src/stores/` хранит состояние сессии, темы и чата в клиенте.
- `src/mocks/` содержит MSW-хендлеры и синтетические данные для изолированных проверок.
- `specs/` содержит [спецификации сценариев](specs/).

Интегрированный интерфейс обращается к Flask через прокси Vite. Сессии, заявки и история чатов сохраняются в PostgreSQL. Контракты описаны в [OpenAPI](../backend/contracts/openapi.yaml).
