# Spec 005 · Чат-бот без ИИ (детерминированный)

## Архитектура
Слой `ChatEngine` скрыт за интерфейсом (`src/chat/engine.ts`):

```ts
interface ChatEngine {
  readonly name: string
  reply(message: string, ctx: ChatContext): ChatReply
}
```

Сейчас используется `createKeywordEngine(intents, fallback)` — сопоставление по ключевым словам. Позже движок заменяется LLM-адаптером с тем же интерфейсом без переписывания UI: UI ходит в `POST /api/chat`, реализацию хендлера меняем изолированно.

## Интенты (фикстура `chat-intents.json`)
| Интент | Примеры ключевых слов | Ответ |
| --- | --- | --- |
| greeting | привет, начать | приветствие + что умею |
| leave | отгул, отпуск, болезнь | как оформить + карточки «Оформить отгул», «Мои запросы» |
| access | доступ, confluence, jira | как запросить + карточки «Запросить доступ», «Инструкция» |
| checklist | чек-лист, план, что дальше | «следующий шаг — {{nextStepTitle}}» + карточка таймлайна |
| contacts | кому, наставник, hr | контакты + карточка наставницы |
| documents | документ, мануал, база знаний | ссылка на базу знаний с пометкой о тестовых данных |
| midterm | экватор, выпускной, опрос | что такое экватор и как готовиться |

## Fallback
Если совпадений нет — бот честно говорит «не понял», называет себя прототипом без ИИ и предлагает карточку наставницы. Никаких выдуманных ответов.

## Шаблоны контекста
`{{userName}}`, `{{mentorName}}`, `{{nextStepTitle}}` — заполняются на стороне мок-сервиса из данных пользователя, контактов и чек-листа.

## Поведение UI
- Задержка ответа 300–1200 мс с индикатором «печатает» (три точки, `aria-label`).
- Подсказки-кнопки с частыми вопросами над полем ввода.
- При сбое сервиса: сообщение «Не доставлено» + кнопка «Повторить» (повторная отправка последнего сообщения).
- История чата сохраняется в localStorage между перезагрузками.

## Критерии приёмки
- [x] Интенты матчатся без учёта регистра, побеждает интент с максимумом совпадений.
- [x] Нераспознанный вопрос → fallback + контакт наставника.
- [x] Сбой сервиса → состояние ошибки с повтором; повтор после восстановления возвращает ответ.
- [x] Тесты движка не требуют сети (`tests/chat-engine.test.ts`).
