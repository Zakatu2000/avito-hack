# Spec 007 · Дизайн-система и доступность

## Токены
Все цвета — CSS-переменные в `src/design/tokens.css`: ступени `green50…green700`, `blue…`, `purple…`, `red…`, `gray50…gray900` вокруг брендовых баз (#04E061, #00AAFF, #965EEB, #FF4053). Пастельные карточки: зелёная `--card-green` (#C9FFC0), голубая `--card-blue` (#B8DAFF), сиреневая `--card-purple` (#DDCCF5). В компонентах запрещены цвета «из головы» — только токены.

## Типографика
Именованные стили `heading-xl/l/m/s`, `body`, `caption` (геометрический гротеск Manrope, подключён пакетом `@fontsource/manrope` без внешних CDN). Заголовки можно подсвечивать маркером (`.hl-green/.hl-blue/.hl-purple`).

## Компоненты и состояния
`Button, Input, Select, DatePicker, Textarea, Card, StatusBadge, ListItem, Timeline, Modal/BottomSheet, Toast, Skeleton, EmptyState, ProgressBar`.
Обязательные состояния: default, hover, focus, disabled, loading (где применимо), error (поля). Витрина — на странице `/design`.

## Цветовая семантика статусов
- зелёный — готово/одобрено; голубой — в процессе/отправлен; фиолетовый — ждёт согласования/на согласовании; красный — отклонено; серый — не начато/черновик.

## Темы и адаптив
- Светлая и тёмная темы через `[data-theme='dark']` (переключатель в шапке/сайдбаре, сохраняется).
- Адаптив: сайдбар ≥900px, мобильная нижняя навигация + BottomSheet <900px; Modal на десктопе / BottomSheet на мобильном (<640px).

## Доступность
- Видимый focus-visible (3px, `--focus-ring`), aria-метки на навигации, диалогах, прогресс-барах, поле чата.
- Live-регионы: чат (`aria-live=polite`), тосты (`role=status`).
- Контраст: тексты на пастелях — тёмные (#0A0A0A/#1A1A1A); зелёные акценты для текста — тёмная ступень green600/700.

## Критерии приёмки
- [x] `/design` показывает палитру, типографику и все компоненты во всех состояниях.
- [x] Обе темы проходят визуальную проверку; переменные тем не дублируются в компонентах.
- [x] Простые действия откликаются <1 c (задержку можно убрать в dev-панели), долгие — со статусом ожидания и обработкой сбоя.
