# Spec 004 · Роли и права

## Роли
| Роль | Описание |
| --- | --- |
| `intern` | Стажёр (Аня Петрова, Марк Соколов) |
| `mentor` | Наставница (Марина Ким) |
| `lead` | Руководитель (Олег Ветров) |

Вход — выбором тестового пользователя на `/login` (без пароля, синтетические данные). Идентификатор передаёт заголовок `x-user-id`, состояние сохраняется в localStorage.

## Матрица прав (проверяется на стороне мок-API, а не только UI)
| Операция | intern | mentor | lead |
| --- | --- | --- | --- |
| `GET /api/checklist` | свой | свой | свой |
| Смена статуса пункта: `in_progress`, `pending_approval`, `done` без согласования | ✅ | — | — |
| `POST /api/checklist/items/:id/approve` (подтверждение чужого пункта) | ❌ 403 | ✅ | ✅ |
| `GET /api/pending-items` (очередь подтверждений) | ❌ 403 | ✅ | ✅ |
| `GET /api/requests` | только свои | все | все |
| `GET /api/requests?scope=queue` | ❌ 403 | ✅ | ✅ |
| `POST /api/requests/:id/approve` / `reject` | ❌ 403 | ✅ | ✅ |
| `POST /api/requests/:id/send` (черновик) | только автор | только автор | только автор |
| `GET /api/interns` (вид команды) | ❌ 403 | ✅ | ✅ |

## Правила UI
- Кнопки недоступных операций стажёру не показываются, НО запрет проверяется и на API: прямой вызов возвращает 403 с кодом `FORBIDDEN`.
- Страница `/team` при 403 показывает отдельное состояние «Нет доступа» (`NoAccess`), а не пустой экран.
- Пункт навигации «Команда» виден только наставнику и руководителю; прямой заход по URL стажёром упирается в 403-состояние.

## Критерии приёмки
- [x] Стажёр не видит вид руководителя и не может подтверждать чужие запросы (API отдаёт 403, тесты закрепляют).
- [x] Наставник и руководитель видят список стажёров с прогрессом, очередь запросов и очередь подтверждений пунктов.
- [x] Все 403-ветки покрыты тестами (`tests/services.test.ts`, `tests/pages.test.tsx`).
