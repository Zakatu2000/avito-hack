# SDD: источники и границы достоверности (A1)

Задача A1, владелец — AI. Каждое утверждение об Авито в SDD, коде и evals
должно прослеживаться к строке этой таблицы или быть помечено как демоданные
/ гипотеза. Проверено: 2026-11-10.

Метки достоверности:

- **VERIFIED FACT** — прочитано в указанном источнике, пункт/лист/страница указаны.
- **DEMO DATA** — синтетические данные прототипа; не являются регламентом Авито
  (кейс, стр. 12, п. 02–03).
- **HYPOTHESIS** — предположение команды; способ проверки обязателен.
