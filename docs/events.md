# События прототипа и пилота (A6)

Владелец — AI · конверт и словарь — `contracts/agent.md` v1.0.0 (B1) ·
реализация — `server/` (Web 2). Сверено с кодом на 2026-11-10.

## Конверт (контракт)

`{eventId, name, occurredAt (UTC), assignmentId}`; дубликаты исключаются по
`eventId`; сырые сообщения и секреты не включаются. Хранилище прототипа —
`onboarding_events` (PostgreSQL), идемпотентность — уникальные индексы
(миграции 003/004).

## Ключевое различие

`task_link_opened` — **намерение** вернуться к задаче (клик по ссылке), а не
подтверждённое начало работы (контракт прямо это фиксирует). Подтверждённое
начало (`task_resumed` по плану) требует отдельного наблюдения в пилоте и
явного действия стажёра; в прототип не добавляем, чтобы не смешивать метрики.
Сервер уже защищает метрику от преждевременной записи: 403, если право не
`granted` (проверено в `server/app.py`, тесты `test_web_integration.py`).

## Находка для команды (handoff Web 1)

`web/src/api/testAdapter.ts` шлёт имя `task_returned`, а контрактный API
принимает только `task_link_opened` (`client.ts` корректен). Тестовый адаптер
расходится с контрактом — поправить при F4/F5.

## Что НЕ является событием

Ответы LLM, клики UI без серверной записи, чтение workspace. Доказательством
действия считается только серверная запись (см. инвариант I-07 SDD).
