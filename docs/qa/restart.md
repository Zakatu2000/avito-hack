# Проверка сохранности после перезапуска

Запустите стенд двойным щелчком по `start.cmd` на Windows или `start.command` на macOS. Из корня проекта на Windows выполните `python scripts/smoke_http.py`, а на macOS выполните `python3.12 scripts/smoke_http.py`.

Проверка создаст синтетический аккаунт и отправит заявку. По подсказке остановите стенд через `Ctrl+C` в окне запуска и снова откройте тот же файл. Когда приложение станет доступно, нажмите `Enter` в окне проверки. Скрипт сравнит сессию и содержание заявки до и после перезапуска. Для проверки подходит отдельная учебная база.
