# Проверка сохранности после перезапуска

Запустите локальный стенд двойным кликом по `start.cmd`. Из корня проекта выполните:

```powershell
python scripts/smoke_http.py
```

Проверка создаст синтетический аккаунт и отправит заявку. По подсказке остановите стенд через `Ctrl+C` в окне запуска и снова откройте `start.cmd`. Когда приложение станет доступно, нажмите `Enter` в окне проверки. Скрипт сравнит сессию и содержание заявки до и после перезапуска. Для проверки подходит отдельная учебная база.
