# Проверка сохранности после перезапуска API

Существующая браузерная проверка описана в README. Дополнительный сценарий
`scripts/smoke_http.py` проверяет, что сессия и отправленная заявка остаются
доступны после перезапуска API.

Запускайте на отдельном учебном стенде, поскольку проверка создаёт синтетический
аккаунт и заявку и перезапускает API. Подготовьте `.env` по README, затем
выполните из корня репозитория:

```sh
export COMPOSE_PROJECT_NAME=avito-restart-check
export FRONTEND_PORT=8080
export PUBLIC_ORIGIN=http://localhost:8080
docker compose up --build -d --wait
python3 scripts/smoke_http.py --base-url http://localhost:8080
```

Если порт занят, измените его в обеих переменных и в аргументе `--base-url`.
Сценарий проверит регистрацию, отправку заявки и совпадение сессии и полной
записи заявки до и после перезапуска. Для прогона достаточно режима AI demo.
