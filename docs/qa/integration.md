## Подтверждено

- React-клиент работает с Flask API через HttpOnly-cookie. Идентичность и роль получаются с сервера.
- Подтверждение передаёт ключ идемпотентности в заголовке, тело отсутствует.
- После перезагрузки восстанавливается сохранённая заявка.
- Оператор в независимой сессии может одобрить заявку и отдельно выдать фактическое право.
- Возврат к задаче записывает task_link_opened. Это намерение стажёра продолжить работу, без подтверждения начала выполнения.
- Браузерный тест Playwright/Chrome прошёл на собранном интерфейсе и реальном API в отдельной временной PostgreSQL-базе.
- Общая команда проверки прошла: 49 тестов Python (48 серверных, один агрегатора), 36 тестов веб-клиента.
- Покрытие Python — 411/449 строк, 91,54%. Покрытие строк веб-клиента — 288/341, 84,45%.
- Суммарно покрыто 699 из 790 строк доступного прикладного кода — 88,48%. Проценты компонентов не усредняются.
- Сборка TypeScript/Vite прошла. После обновления инструментов установки npm сообщает 0 уязвимостей.
- OpenAPI и 13 синтетических примеров проходят проверку.

## Оставшиеся проверки

AI использует явный детерминированный демоадаптер. Модуль ai/ ещё отсутствует в доступных ветках. Итоговое покрытие проекта и проверка --release ожидают подключения AI.
