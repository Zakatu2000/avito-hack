# Проверка серверной сборки · 10 ноября 2026

Проверено локально на Python 3.12 и PostgreSQL 16.2.

- OpenAPI и 13 JSON-примеров проходят проверку.
- 45 интеграционных тестов сервера проходят.
- Проверка агрегатора покрытия проходит отдельно.
- Coverage.py учитывает 407 исполняемых строк прикладного Python-кода, покрыта 371 строка — 91,15%.
- В расчёт входят server/app.py, access.py, dialog.py, operator_demo.py и store.py. Тесты и зависимости исключены. SQL-миграции выполняются в интеграционных тестах; процент coverage.py относится к Python.
- Полный командный показатель ожидает web/ и ai/. Параметр --release завершает проверку ошибкой до их появления.
- Dockerfile и Compose подготовлены; структура YAML, локальная привязка порта и зависимости сервисов проверены. Docker на машине проверки отсутствует, сборка образа и запуск Compose ещё требуют проверки.
- reports/ содержит воспроизводимые JSON-отчёты после запуска scripts/check.py. Эти файлы исключены из Git и создаются при проверке.

Деморежим использует серверный адаптер с детерминированными ответами. Живой LLM-провайдер и пользовательский веб-интерфейс ожидаются от участников AI и Web 1. Полная приёмка B6 завершится после их подключения и запуска проверки --release.
