# Проверка AI A1–A6 · финальная сборка (ветка main) · 2026-11-10, live-eval 2026-11-11

Все числа — фактические прогоны этой сессии (окружение: Windows 11,
Python 3.12.10, Node v22.14.0, PostgreSQL 16 в docker). Данные синтетические.

## Архитектура проверяемого

Модуль ai/ подключён к стандартному POST /api/messages. В demo действует
детерминированная политика по ключевым словам (воспроизводимо, без ключа);
в live LLM интерпретирует намерение из закрытого набора
(`blocker_access`, `ask_next_step`, `ask_request_status`, `ask_mentor`,
`off_topic`, `unclear`) и формулирует текст — вид решения, факты и
идентификаторы остаются за политикой и сервером (см. `docs/sdd/agent.md`,
«Роль LLM»). Текст LLM проверяется на непротиворечие фактам (ID ⊆ факты;
статусы и «право выдано» — только при подтверждении); нарушение,
невалидный JSON или `finish_reason != stop` → детерминированный фолбэк;
ошибки транспорта → 503 без подмены режима.

## Полный live-eval (2026-11-11, эта сборка)

Датасет расширен 18 записями `EVAL-LIVE-*` (`providerMode=live`; офлайн-гейт
40/40 не затронут — записи SKIP без `--live`). Прогон:
`cd ai && python -m evals.runner --live` против `deepseek-flash`
(DeepSeek-V4.1-Flash-1017), ключ из `ai/.env`, в репозитории отсутствует.

- **Итог: 58/58** (40 офлайн + 18 live), exit 0.
- Первый прогон дал 55/58; нарушения исправлены до передачи (plan.md A5):
  1. LIVE-02/03 — расплывчатые жалобы («я застрял с первой штукой») модель
     изредка трактовала как `unclear` → clarify. В SYSTEM_POLICY добавлено
     явное правило: «застрял/не продвигается по первой задаче при отсутствии
     доступа в фактах» = `blocker_access`.
  2. LIVE-09 — при выданном праве и ОТСУТСТВИИ заявки текст LLM ссылался на
     несуществующую заявку; гард её пропускал (статусных утверждений не было).
     Гард расширен: `granted` + нет заявки → запрет упоминания «заявк» в
     тексте LLM (фолбэк на детерминированный clarify). Регрессионный тест —
     `test_request_mention_when_granted_without_ticket_falls_back`.
  3. LIVE-18 — ожидание записи было строже контракта (голая подстрока
     «выдан» ловила честные оговорки вида «неизвестно, выдан ли доступ»).
     Реальные ответы модели по этому состоянию проверены вручную (3 прогона,
     kind=clarify, без ложных утверждений); ожидание приведено к семантике
     гарда — запрещены утверждения «доступ выдан / подтверждён / право
     выдано», а не любое упоминание слова.
- LLM недетерминирован по природе, но на этом наборе стабилен: повторные
  прогоны 2026-11-11 дали 4/4 × 58/58 (итого 5/5 с учётом основного), все 18
  live-записей проходят в каждом прогоне. Переносимость на более широкий
  набор формулировок и будущие версии модели — предмет пилота.

## Честные ограничения

- Полный live-eval выполнен 2026-11-11 (58/58, см. раздел выше); повторные
  прогоны 4/4 × 58/58 — на этом наборе распознавание стабильно. Точность на
  более широком наборе формулировок остаётся предметом пилота.
- Исторические smoke-запросы GLM (10 ноября, 3 ситуации, 1,23–1,48 с)
  выполнялись предыдущей сборкой с другой реализацией — к этой версии кода
  не относятся; новый smoke DeepSeek см. выше.
- Датасет — синтетика (DEMO-01/02), тексты на русском; произвольные
  формулировки в demo дают clarify по конструкции (ключевые слова),
  полнота распознавания — предмет live-eval/пилота.
- Наблюдение live-стенда (2026-11-11): текст LLM может быть осторожнее
  решения — в propose-состоянии формулировка звучала как уточняющий вопрос
  при уже созданном предложении. Контракт не нарушается (kind/идентификаторы
  из фактов), но тон текста на граничных intent'ах — кандидат в наблюдения
  пилота.
- Покрытие строк ≠ доля успешных eval-ответов; отчёты не смешиваются.

## Сеть, формат и ошибки (моками)

- Провайдер: OpenAI-совместимый chat-completions endpoint (env `AI_*`,
  алиасы `DEEPSEEK_*`); `response_format=json_object`, один retry на пустой
  ответ, fail-fast по 429/5xx/timeout (`ai/tests/test_deepseek.py`,
  `test_providers.py`).
- Конфигурация: live без полного набора AI_BASE_URL/AI_MODEL/AI_API_KEY —
  ошибка старта, без скрытого fallback в demo (`ai/tests/test_settings.py`,
  обе схемы имён env проверены).
- Тайм-аут провайдера строго меньше бюджета раннера — проверяется при
  старте сервера.
