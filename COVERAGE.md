## Как воспроизвести

Установите зависимости по [инструкции в README](README.md#тесты-и-покрытие). Для Python задайте `TEST_ADMIN_DATABASE_URL` отдельного кластера PostgreSQL с правом создавать тестовые базы.

Из `frontend/`:

```sh
npm run test:coverage
```

Vitest сохранит детальный отчёт в `frontend/coverage/index.html` и данные для инструментов анализа в `frontend/coverage/lcov.info`.

Из `backend/` в виртуальном окружении:

```sh
python scripts/check.py
```

Coverage.py сохранит отчёт по файлам и строкам в `backend/reports/python-coverage.json`.
